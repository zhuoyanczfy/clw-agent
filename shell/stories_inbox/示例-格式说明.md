这是一个示例故事文件。

每篇小小说 = 一个 .txt / .md 文件：
1. 文件名就是标题（如「一碗阳春面.md」），也可以用上面的「标题：」覆盖
2. 「分类：」和「来源：」可单独设置，不写则用命令行默认值
3. 头部元信息以单独一行 --- 结束，--- 之后是正文
4. 把文件放进 shell/stories_inbox/（或任意目录），运行：
   python import_stories.py            # 批量导入云服务器
   python import_stories.py --dry-run  # 先预览再上传
